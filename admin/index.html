Device telemetry

Registered devices report model, Android version, SIM carrier, SIM number, battery level, charging state, network type and system resources. Telemetry refreshes with every heartbeat (roughly every 30 seconds while the app is in the foreground).

Security reminder

Keep SESSION_SECRET, ADMIN_API_KEY, database credentials and administrator password on the server. Never place secrets in this HTML file or expose them in browser JavaScript.

Remote support consent

Only support devices whose owners have knowingly approved the session. A client-supplied approval flag alone is not proof of consent.
